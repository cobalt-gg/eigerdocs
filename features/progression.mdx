## Eiger design

Progression registers versioned profile data, reward events, unlock conditions, and UI notifications. It must never be required for an experience to start or for core equipment to function.

## Possible models

Campaign checkpoints, cosmetic unlocks, class unlocks, weapon progression, challenge tracking, and seasonal rewards can each be supplied by a Cobalt game without becoming framework defaults.

## Phase

Keep the extension points in P1. Build actual progression systems only for the first game that needs them; service-backed economies and battle passes are P3.
