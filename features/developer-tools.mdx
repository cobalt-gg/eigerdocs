## Required tools

- Data Asset validation with actionable fixes.
- A debug overlay for experience, modules, player state, camera, input, inventory, abilities, and network role.
- Console commands for travel, spawning, loadouts, damage, latency simulation, and reset.
- Gameplay event tracing and readable log categories.
- Module sample maps and content audits.

## Phase

Core validation and the debug overlay are P0. Wizards, visual flow inspectors, and bulk migration tools are P2 after workflows stabilize.
