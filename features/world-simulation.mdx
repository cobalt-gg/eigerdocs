## Scope

Day/night cycles, weather, storms, temperature, fog, hazards, power systems, alarms, dynamic lights, water, fire, wildlife, ambient life, and world events.

## Design

Simulation services emit state and events. Maps choose which systems run and whether state is cosmetic, match-scoped, or persistent.

## Phase

P2. Start with a weather/time service only when it visibly supports a target experience.
