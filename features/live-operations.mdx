## Scope

Feature flags, remote balance values, rotating playlists, announcements, experiments, telemetry, privacy, emergency disablement, and version compatibility.

## Design

Eiger provides interfaces and safe local fallbacks. A Cobalt game chooses service providers, consent policy, analytics events, and operational ownership.

## Phase

P3. Build local Data Asset tuning first, then introduce remote control only with clear release operations.
