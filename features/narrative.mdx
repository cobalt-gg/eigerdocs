## Eiger design

Eiger provides interaction-driven dialogue triggers, quest/objective events, checkpoint hooks, subtitle presentation, and save contributors. It does not dictate a dialogue graph editor, writer workflow, quest format, or cinematic pipeline.

## Why it is modular

A shooter can use a one-line mission prompt. A story game can integrate a full narrative tool. Both should talk to Eiger through the same interaction, objective, UI, and save contracts.

## Phase

Basic hooks are P1. A complete story sample is Phase 4. Advanced dialogue tooling is selected only when a Cobalt game needs it.
