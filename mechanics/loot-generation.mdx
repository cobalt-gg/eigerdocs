## Behavior
At map load or event activation, select items from a deterministic or random table within rarity, location, player-count, and progression constraints.
## Eiger contract
Uses item definitions, map points, and optional economy. Configure tables, seed, reroll, respawn, ownership, and anti-duplication policy. Requires inventory/pickups.
