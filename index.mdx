## The product in one sentence

Eiger is a configurable Unreal Engine foundation that lets you assemble a first-person or third-person game from reusable systems instead of rebuilding core gameplay for every project.

It supports arcade shooters, tactical shooters, battle royale experiences, co-op or competitive modes, and games where combat is only one part of the experience.

## Product principles

- Build features as opt-in modules, not one required game loop.
- Make common changes available through data and editor tools before code changes.
- Treat networking, save data, and accessibility as core requirements.
- Keep a small, polished playable slice working throughout development.
- Prefer stable contracts between modules over deep dependencies.

## Definition of success

By the first major release, a small team can start a new Cobalt game, choose a camera and movement profile, equip a weapon, configure an ability and game mode, and play it in a networked test level without editing Eiger internals.
